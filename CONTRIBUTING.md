# Contributing

Thanks for your interest in Vibe Coding Lab.

This repository is a public index of independent projects, not a shared codebase for all projects.

## What belongs here?

- Public project listings and descriptions.
- Links to public repositories and demos.
- Category documentation and templates.
- Improvements to this index and workflow.

## What does not belong here?

- Private project source code or private repository metadata.
- API keys, tokens, credentials, or real `.env` files.
- Confidential data, private user information, or assets without permission.

## Updating the index

When adding a project, make sure its repository is public and the project owner intends to share it. Add it to the relevant category README and keep the description accurate.

For changes, open a pull request with a short explanation and any relevant preview.
