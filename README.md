:::01 / THE LAB
A personal playground for building, testing, and shipping ideas.

Vibe Coding Lab is where curiosity turns into working software ---
from quick prototypes and AI experiments to useful tools, interfaces,
and early-stage product ideas.

This repository is the public index, not a monolithic codebase.
Every substantial project lives in its own repository, with its own
stack, documentation, and release cycle.
Build first. Experiment freely. Organize intelligently. Publish when
ready.

06 / THE RULES
- Separate repositories: each substantial project gets its own
  repository.
- Public by intention: only projects ready to be shared are listed
  here.
- Private means private: private project names, source code,
  credentials, and internal notes do not belong in this public index.
- Document the useful parts: explain the problem, setup,
  decisions, and what was learned.
- Keep improving: experiments can evolve, be archived, or become
  standalone products.
See [CONTRIBUTING.md](CONTRIBUTING.md) and [WORKFLOW.md](WORKFLOW.md)
for the practical details.
