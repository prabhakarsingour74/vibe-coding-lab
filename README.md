## 01 / THE LAB

A personal playground for building, testing, and shipping ideas.

**Vibe Coding Lab** is where curiosity turns into working software — from quick prototypes and AI experiments to useful tools, interfaces, and early-stage product ideas.

This repository is the **public index**, not a monolithic codebase. Every substantial project lives in its own repository, with its own stack, documentation, and release cycle.

> Build first. Experiment freely. Organize intelligently. Publish when ready.

## 06 / THE RULES

- **Separate repositories:** Each substantial project gets its own repository.
- **Public by intention:** Only projects ready to be shared are listed here.
- **Private means private:** Private source code, credentials, and confidential notes stay out of this public index.
- **Document the useful parts:** Explain the problem, setup, decisions, and lessons learned.
- **Keep improving:** Experiments can evolve, be archived, or become standalone products.

See [WORKFLOW.md](WORKFLOW.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
